# EXACT VERSIONS OF EVERY LIBRARY VERTCUT INSTALLS
#
#   pip install . -c constraints.txt
#
# `pyproject.toml` says what Vertcut needs ("faster-whisper 1.1 or
# newer"); this file says which versions were actually checked together,
# including everything those pull in. pip takes from here only what it
# needs on this computer: colorama, for example, comes only on Windows.
#
# WHY. On 29 September 2026 av 19 came out, and every fresh install of
# Vertcut — the installer included — got it and could no longer read the
# sound of any video. Nothing changed on our side: a library two steps
# away did. With this file, a new release of anything changes nothing
# for people until it has been checked here.
#
# WHO USES IT: the installer (it travels in the download next to it),
# the install and update commands in README.md and INSTALL.md, and the
# build machines. A weekly check installs the NEWEST versions without
# this file and runs a real analysis and export; when it goes red,
# something new has broken, and this file is what keeps people safe.
#
# HOW TO UPDATE: see CONTRIBUTING.md. In short — change the numbers,
# run `python tools/pins.py`, push, and let the build machines go green.
#
# These are the versions the build machines installed on 9 October 2026,
# when every check of the 0.1.0 release passed on them: Windows (the
# installer and the README commands), Linux (the README commands) and
# macOS (the downloaded installer, a real analysis and export).
